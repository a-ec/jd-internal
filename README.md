Steps for making changes : - 


1. git pull origin main # Do this in main branch

2. git checkout -b "branch-name" - # Create a new branch and make changes there

3. git add .   - # Add changes to your commit

4. git commit -m "Commit message" - Create a commit for your changes , can do multiple if want to do under one push / pull request

5. git push --set-upstream origin branch-name    - # Push your changes and create a pull request, this will create link to make pull request

6. Make your pull request , # add a description of changes , create pull request , merge , delete branch (optional: Request reviewers)
